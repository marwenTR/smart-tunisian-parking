# Smart Tunisian Parking Management System

A professional desktop application for automated vehicle parking management, built with Python, CustomTkinter, OpenCV, and YOLOv8.

## Features
- **Live Dashboard:** Real-time statistics on parked vehicles and available spaces.
- **Vehicle Detection:** YOLOv8 AI model detects cars, trucks, and motorcycles.
- **Simulation Mode:** Test the AI pipeline without a webcam using prerecorded videos and images.
- **Tunisian Plate Recognition:** OCR pipeline designed for Tunisian license plates (In Progress).
- **Data Persistence:** SQLite database ensuring no duplicate entries and accurate duration tracking.
